## GitHub Integration

<Steps>
  <Step title="Connect Repository" icon="git-branch">
    Link your GitHub repository to a hypr documentation space.
  </Step>
  <Step title="Configure Sync" icon="refresh-cw">
    Set up automatic synchronization of documentation files.
  </Step>
  <Step title="Map Branches" icon="git-branch">
    Associate repository branches with documentation versions.
  </Step>
</Steps>

<CodeGroup tabs="GitHub Actions">
  ````yaml
  name: Sync Documentation
  on:
    push:
      paths:
        - 'docs/**'
  jobs:
    sync:
      runs-on: ubuntu-latest
      steps:
        - uses: actions/checkout@v2
        - name: Sync to hypr
          uses: hypr/github-action@v1
          with:
            api-key: ${{ secrets.HYPR_API_KEY }}
            space-id: ${{ secrets.HYPR_SPACE_ID }}
  ````
</CodeGroup>

<Callout kind="info">
  GitHub integration supports both push and pull synchronization, keeping your documentation in sync with your code.
</Callout>

  <Step title="Connect Jira" icon="check-square">

  </Step>

    Associate Jira projects with documentation spaces.

  </Step>

<Expandable title="Issue Linking" default-open="false">
  | Jira Field | hypr Mapping |

</Expandable>

## Webhook Integration

<CodeGroup tabs="Webhook Example">
  ````json
  {
    "event": "document.published",
    "spaceId": "space_123",
    "documentId": "doc_456",
    "timestamp": "2024-01-15T10:30:00Z",
    "data": {
      "title": "API Reference",
      "author": "john.doe@company.com",
      "url": "https://hypr.com/docs/api-reference"
    }
  }
  ````
</CodeGroup>

<ExpandableGroup>
  <Expandable title="Supported Events" default-open="true">
    - `document.created`
    - `document.updated`
    - `document.published`
    - `document.deleted`
    - `space.created`
    - `user.invited`
  </Expandable>
  <Expandable title="Security" default-open="false">
    All webhooks include HMAC signatures for verification.
  </Expandable>
</ExpandableGroup>
