## Release History

<Update label="2024-10-15" description="v2.1.0" tags={["feature", "improvement"]}>

## New Features

- Introduced real-time collaborative editing for team documents
- Added document templates to speed up content creation
- Implemented advanced search with filters and sorting options
- Launched integrations marketplace with pre-built connectors

## Improvements

- Enhanced performance for spaces with large numbers of documents
- Improved mobile responsiveness across all device types
- Updated user interface with modern design elements
- Optimized API response times for better user experience

</Update>

<Update label="2024-09-20" description="v2.0.0" tags={["feature", "breaking"]}>

## New Features

- Complete redesign of the documentation editor with rich text support
- Added support for multiple documentation spaces per organization
- Introduced role-based access control for enhanced security
- Launched public API for third-party integrations

## Breaking Changes

- API endpoints now require authentication for all requests
- Document URLs have changed to include space identifiers
- Webhook payload format has been updated for consistency

</Update>

<Update label="2024-08-10" description="v1.5.0" tags={["feature", "bugfix"]}>

## New Features

- Added support for Markdown and HTML content formats
- Introduced document versioning and change tracking
- Launched Slack integration for team notifications
- Added export functionality for PDF and HTML formats

## Bug Fixes

- Fixed issue with document search not returning accurate results
- Resolved problem with webhook delivery failures
- Corrected display issues in the mobile interface
- Fixed authentication token expiration handling

</Update>
