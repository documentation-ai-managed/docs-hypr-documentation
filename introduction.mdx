## Welcome to hypr Documentation

Whether you're building APIs, creating guides, or maintaining technical knowledge bases, hypr streamlines the process of creating, sharing, and collaborating on documentation.

## Getting Started

<CodeGroup tabs="CLI,API">
  ````bash
  # Install hypr CLI
  npm install -g @hypr/cli
  
  # Initialize a new documentation space
  hypr init my-docs
  
  # Start the development server
  hypr dev
  ````
  ````javascript
  // Initialize hypr client
  const hypr = require('@hypr/sdk');
  
  const client = new hypr.Client({
    apiKey: 'your-api-key',
    spaceId: 'your-space-id'
  });
  
  // Create a new document
  await client.documents.create({
    title: 'Getting Started Guide',
    content: '# Welcome to hypr'
  });
  ````
</CodeGroup>

<Callout kind="info">
  Before you begin, make sure you have Node.js version 14 or higher installed on your system.
</Callout>
