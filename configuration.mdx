## API Configuration

<Steps>
  <Step title="Generate API Keys" icon="key">
    Create API keys with appropriate permissions.
  </Step>
  <Step title="Configure Endpoints" icon="link">
    Set up custom API endpoints if needed.
  </Step>
  <Step title="Test Connections" icon="check-circle">
    Verify your API configuration works correctly.
  </Step>
</Steps>

<CodeGroup tabs="JavaScript,Python,cURL">
  ````javascript
  const hypr = require('@hypr/sdk');
  
  const client = new hypr.Client({
    apiKey: process.env.HYPR_API_KEY,
    baseUrl: 'https://api.hypr.com/v1'
  });
  
  // Test connection
  client.spaces.list().then(spaces => {
    console.log('Connected successfully');
  });
  ````
  ````python
  import os
  from hypr import Client
  
  client = Client(
      api_key=os.getenv('HYPR_API_KEY'),
      base_url='https://api.hypr.com/v1'
  )
  
  # Test connection
  spaces = client.spaces.list()
  print('Connected successfully')
  ````
  ````bash
  curl -H "Authorization: Bearer $HYPR_API_KEY" \
       -H "Content-Type: application/json" \
       https://api.hypr.com/v1/spaces
  ````
</CodeGroup>

## Environment Variables

<Expandable title="Required Environment Variables" default-open="false">
  | Variable | Description | Required |
  |----------|-------------|----------|
  | `HYPR_API_KEY` | Your API key for authentication | Yes |
  | `HYPR_BASE_URL` | API base URL | No |
  | `HYPR_SPACE_ID` | Default space ID | No |
</Expandable>

<Callout kind="alert">
  Never commit sensitive configuration values like API keys to version control.
</Callout>
