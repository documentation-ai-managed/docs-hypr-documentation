## Authentication Overview

Hypr uses a secure authentication system to protect your documentation spaces and control access to sensitive content. You can authenticate using API keys, OAuth tokens, or integrate with your organization's identity provider for single sign-on capabilities.

<Tabs>
  <Tab title="API Keys" icon="key">
    <Steps>
      <Step title="Generate API Key" icon="plus">
        Navigate to your account settings and create a new API key.
      </Step>
      <Step title="Set Permissions" icon="shield">
        Choose the appropriate permissions for the key based on your needs.
      </Step>
      <Step title="Use in Requests" icon="send">
        Include the API key in your request headers for authentication.
      </Step>
    </Steps>
  </Tab>
  <Tab title="OAuth" icon="lock">
    <CodeGroup tabs="JavaScript,Python">
      ````javascript
      // Initialize OAuth flow
      const oauth = new hypr.OAuth({
        clientId: 'your-client-id',
        redirectUri: 'https://your-app.com/callback'
      });
      
      // Start authentication
      const authUrl = oauth.getAuthUrl();
      window.location.href = authUrl;
      ````
      ````python
      from hypr import OAuth
      
      oauth = OAuth(
          client_id='your-client-id',
          redirect_uri='https://your-app.com/callback'
      )
      
      # Get authorization URL
      auth_url = oauth.get_auth_url()
      print(f"Visit: {auth_url}")
      ````
    </CodeGroup>
  </Tab>
</Tabs>

## API Key Authentication

API keys provide a simple way to authenticate requests to the hypr API. You can generate keys with different permission levels to control what actions they can perform.

<Callout kind="info">
  Always store your API keys securely and never commit them to version control.
</Callout>

<Expandable title="API Key Permissions" default-open="false">
  | Permission | Description |
  |------------|-------------|
  | `read` | View documents and spaces |
  | `write` | Create and edit documents |
  | `admin` | Manage spaces and users |
  | `delete` | Remove documents and spaces |
</Expandable>

## OAuth Integration

For more advanced authentication scenarios, hypr supports OAuth 2.0 integration. This allows you to use existing identity providers like Google, GitHub, or your company's SSO system.

## Troubleshooting Authentication

<Callout kind="alert">
  If you're experiencing authentication issues, first check that your API key is valid and has the correct permissions.
</Callout>

<Steps>
  <Step title="Verify API Key" icon="check-circle">

  </Step>
  <Step title="Check Permissions" icon="shield">

## Single Sign-On (SSO)

Hypr supports SAML-based SSO integration for enterprise customers. This allows users to authenticate using their corporate credentials without needing separate hypr accounts.

<CodeGroup tabs="SAML Configuration">
  ````xml
  <!-- Example SAML metadata -->
  <EntityDescriptor entityID="https://your-company.com/saml/metadata">
    <SPSSODescriptor protocolSupportEnumeration="urn:oasis:names:tc:SAML:2.0:protocol">
      <AssertionConsumerService index="0" isDefault="true"
        Binding="urn:oasis:names:tc:SAML:2.0:bindings:HTTP-POST"
        Location="https://your-app.hypr.com/saml/acs" />
    </SPSSODescriptor>
  </EntityDescriptor>
  ````
</CodeGroup>
